Show the versions of all memlab packages installed

```bash
memlab version 
```

## Example output

```text
$ memlab version

 memlab@2.0.7
 @memlab/heap-analysis@2.0.7
 @memlab/e2e@2.0.7
 @memlab/core@2.0.7
 @memlab/cli@2.0.7
 @memlab/api@2.0.7
```

## Options

The [universal options](./CLI-commands.md#universal-options) (`--help`, `--verbose`, ...) work with this command too.
