$ memlab help find-leaks

  memlab find-leaks
  Find memory leaks in heap snapshots

[90m    There are three ways to specify inputs for the `memlab find-leaks` command:[0m
[90m     1. `--baseline`, `--target`, `--final` specifies each heap snapshot input individually;[0m
[90m     2. `--snapshot-dir` specifies the directory that contains all three heap snapshot files (MemLab will assign[0m
[90m    baseline, target, and final based on alphabetic order of the file);[0m
[90m     3. `--work-dir` specifies the output working directory of the `memlab run` or the `memlab snapshot` command;[0m

[90m    Please only use one of the three ways to specify the input.[0m

[90m    You can also manually take heap snapshots in Chrome Devtools, save them to disk.[0m
[90m    Then process them using this command with the CLI flags (either option 1[0m
[90m    or option 2 mentioned above).[0m
