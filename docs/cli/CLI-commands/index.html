Command Line Interface

Install the memlab command line tool with npm:

npm install -g memlab

COMMON Commands​

CommandDescription
memlab runFind memory leaks in web apps
memlab anonymizeRemove user data from a heap snapshot so it can be shared
memlab find-leaksFind memory leaks in heap snapshots
memlab class-diffCompare the number of objects and their self size per class between two heap snapshots
memlab class-histogramPrint the number of objects and their total self size per class in a heap snapshot
memlab class-trendTrack the number of objects per class across a series of heap snapshots, and list the classes that grew at every step
memlab diff-leaksFind new memory leaks by diffing control and test heap snapshots
memlab dom-auditCount the DOM elements attached to the document in a browser heap snapshot, by tag and by repeated element
memlab find-objectsList the objects in a heap snapshot that match a class name, node type, retained size or detached state, largest retained size first
memlab traceReport retainer trace of a specific node, use with --nodeId
memlab analyzeRun heap analysis on heap snapshots.
memlab heap-statsSplit the memory in a heap snapshot into code, strings, JS arrays, system objects and native memory, and into loaded code vs memory the program allocated
memlab native-contextsSplit a heap snapshot by JavaScript realm (page, iframes, extension worlds, detached windows, Node.js vm contexts) and report the memory each one owns
memlab script-censusReport the source text of loaded scripts kept in a heap snapshot, and scripts kept in memory more than once
memlab sliced-stringsFind large strings kept alive by short substrings (V8 sliced strings) in a heap snapshot
memlab snapshot-headerPrint node and edge counts and the memory needed to analyze a heap snapshot, read from its header without parsing the snapshot
memlab weakref-censusCount the WeakRefs in a heap snapshot, live vs empty, grouped by what holds them
memlab heapInteractive command to explore a single heap snapshot
memlab view-heapInteractive command to view a single heap snapshot

MISC Commands​

CommandDescription
memlab versionShow the versions of all memlab packages installed
memlab listList all test scenarios
memlab resetReset and initialize all directories
memlab measureRun test scenario in measure mode
memlab warmupWarm up the target app
memlab helpList all MemLab CLI commands or print helper text for a specific command
memlab get-default-work-dirQuery the default working directory
memlab snapshotInteract with web app and take heap snapshots
memlab warmup-and-snapshotWarm up server and take heap snapshots

Universal Options​

These options work with every command:

  • --help, -h: print helper text
  • --verbose, -v: show more details
  • --sc: set to continuous test mode
  • --debug: enable manual debugging
  • --silent, -s: mute all terminal output
