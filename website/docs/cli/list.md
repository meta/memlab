List all test scenarios

```bash
memlab list 
```

## Example output

```text
$ memlab list
All available apps and interactions:

default-app-for-scenario:

test-spa: link-3
```

## Options

The [universal options](./CLI-commands.md#universal-options) (`--help`, `--verbose`, ...) work with this command too.
