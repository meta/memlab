  Each dialog still has an [36munsubscribe[0m closure stored on it, so the close path apparently never
  calls it. The fix: call [36munsubscribe()[0m on close and [36mopenedDialogs.delete(container)[0m.

  What a fix saves, measured on the last snapshot:
  - Removing the dialogs frees 3.1 MB (68% of a 4.5 MB heap), about 787 KB per open/close. 99% of
    that is each dialog's [36mhistory[0m array (781 KB).

  - Together that's ~3.3 MB, which covers almost all of the 3.5 MB the heap grew.
